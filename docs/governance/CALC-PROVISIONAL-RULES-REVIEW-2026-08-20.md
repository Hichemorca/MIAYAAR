# MIAYAAR — سجل قرار مراجعة قواعد CALC المؤقتة

**التاريخ:** 2026-08-20  
**النطاق:** حصر وتصنيف وتوثيق `CALC-008` إلى `CALC-016` فقط.  
**نوع السجل:** مراجعة حوكمة قراءة فقط؛ ليست إصداراً منهجياً، ولا تعتمد قاعدة حسابية جديدة.  
**المصدر الكانوني النافذ:** `MIAYAAR-METH-001` v1.2، المعرّف كمصدر منهجي مجمّد في ADR-011.[1]

## القرار

لا تعتمد هذه المراجعة أي قاعدة من السلسلة `CALC-008` إلى `CALC-016` كقاعدة منهجية معتمدة. تبقى القواعد المنفذة موسومة صراحةً بـ`PROVISIONAL`، ولا تعيد هذه الوثيقة تفسير قيمة تاريخية أو أوزان سيناريو أو عوامل تسعير أو مخرجات تقييم.

> «No historical valuation must be reinterpreted by changing the frozen v1.2 numeric configuration.» — ADR-011.[1]

ينفذ المحرك الحالي قواعد تشغيلية مسماة وموسومة بأنها مؤقتة، ثم يضيف تحذير `VAL_WARN_PROVISIONAL_POLICY` إلى سجل القرار عند استعمال أي منها.[2] ويظل هذا الإفصاح ضرورياً، لأن وثيقة المنهجية الأقدم تصف الأغراض والمدخلات وبعض الافتراضات، لكنها لا تحسم بالقدر التشغيلي الكافي جميع صيغ الحساب أو ترتيب التطبيق أو السلوك عند غياب منهج.[3]

| رمز التصنيف                             | المعنى الحاكم                                                                                      | الأثر في هذه المراجعة                                          |
| --------------------------------------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **D — موثق جزئياً، غير معتمد تشغيلياً** | توجد نية أو مدخلات أو افتراضات في الوثائق، لكن الصيغة أو نطاق التطبيق أو قاعدة التراجع غير محسومة. | يبقى الرمز `PROVISIONAL`؛ لا يُعامل النص كإقرار بالصيغة.       |
| **U — غير محسوم في السياسة**            | لا توجد قاعدة موثقة تحدد السلوك التشغيلي محل المراجعة.                                             | لا يجوز استنتاج قاعدة أو عتبة أو fallback.                     |
| **I — فجوة هوية**                       | الرمز مدرج في مجال التحذير، لكن لا تعريف أو تنفيذ أو اختبار خاصاً له في المصدر والتاريخ المتاحين.  | لا يمكن اعتماد الرمز قبل تعريفه أو تصحيح المجال الذي يعلن عنه. |

## ما هو محسوم وما هو غير محسوم

المحسوم هو أن التهيئة الرقمية للأوزان والافتراضات والعوامل في v1.2 تظل مجمدة ويجب أن تُقرأ من مصدرها الكانوني على الخادم فقط.[1] [4] كما أن المحرك لا يخفي الطبيعة المؤقتة للقواعد: تظهر السياسة في metadata والتحذيرات، وتؤدي التحذيرات حالياً إلى نتيجة جزئية.[2]

غير المحسوم هو اعتماد السلوكيات التسعة أعلاه كمنهجية رسمية. لا تكفي الجداول أو افتراضات السوق الحالية لإقرار صيغ NOI أو التكلفة أو DCF، أو قرار تجميع العوامل وإعادة وزن المناهج، أو إحصاء المقارنات، أو سياسة حالة النتيجة. كما أن `CALC-015` فجوة ترقيم موثقة، لا قاعدة كامنة يجوز تخمينها.

## بوابة أي اعتماد لاحق

أي تحويل لاحق لقاعدة من هذه السلسلة إلى قاعدة معتمدة يتطلب إصداراً منهجياً مستقلاً وفق ضوابط ADR-011 ووثيقة التغيير: تعريف قابل للاختبار، مصدر بيانات وإثبات أصل، نطاق property type، سياسة بيانات ناقصة، تحقق رجعي أو اختبار مناسب، مراجعة مهنية مستقلة، وموافقة مالك المنهجية.[1] [3] لا يجيز هذا السجل كتابة أو تعديل قيم أو معاملات أو أوزان قبل استيفاء تلك البوابة.

## أثر التنفيذ

لم يتغير أي ملف مصدر تشغيلي أو عقد أو اختبار أو قاعدة بيانات. لا تتغير `valuation.run` أو `ValuationEngine` أو `methodology-v1_2.ts` أو الأوزان أو العوامل أو اختيار المقارنات أو قيم التقييم. يضيف هذا السجل فقط تفسيراً حوكمياً قابلاً للمراجعة لما يفصح عنه المحرك حالياً.
