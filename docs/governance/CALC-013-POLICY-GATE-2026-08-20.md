# CALC-013 — POLICY GATE

**التاريخ:** 2026-08-20  
**الحالة:** `DIRECTION A SELECTED — PROPOSED ADR REQUIRED BEFORE ANY IMPLEMENTATION`
**النطاق:** مراجعة حوكمية قراءة فقط لسلوك إعادة تطبيع أوزان المناهج المتاحة.  
**خارج النطاق:** أي تغيير في الكود أو الأوزان أو المخرجات أو العقود أو قاعدة البيانات أو المنهجية المجمدة v1.2.

## القرار الحاكم

لا تعتمد هذه البوابة قاعدة `CALC-013` ولا تغير أي مخرج تقييم. يظل السلوك القائم **مؤقتاً** إلى أن يختار مالك المنهجية سياسة صريحة لحالة غياب منهج ذي وزن موجب. لا تستنتج هذه الوثيقة قيمة أو عتبة أو coefficient أو fallback rule من بيانات DLD أو من التنفيذ الحالي.

> `PROVISIONAL — CALC-012/CALC-013: the adjustment aggregation and missing approach reweighting rule are not approved.` — تعليق المصدر التشغيلي الحالي.[1]

## ما هو محسوم

المحرك الحالي يجمع فقط المناهج التي أنتجت نتيجة قابلة للاستخدام في سيناريو معين. ويحسب مجموع أوزان تلك المناهج (`activeWeight`)، ثم يستبدل وزن كل منهج متاح بـ`configuredWeight / activeWeight`. يرفض التجميع فقط إذا كان مجموع الأوزان النشطة غير منتهٍ أو لا يزيد على صفر.[1] ويوسَم كل مخرج ناتج بـ`normalizedActiveWeight: true` و`PROVISIONAL_CALC-012_CALC-013`، كما يعرض التحذير العام هذه القاعدة ضمن سياسات الحساب المؤقتة.[1] [2]

تظل الأوزان الكاملة لكل نوع عقار ولكل سيناريو مصدراً كانونياً مجمداً في `methodology-v1_2.ts`. على سبيل المثال، تضم أوزان الشقق الأساسية المناهج الأربع، بينما تضم أوزان الأرض مقارنة المبيعات وDCF فقط.[3] ولا يغير ADR-011 هذا التكوين أو يسمح بإعادة تفسير التقييمات التاريخية.[4]

تحدث حالة غياب المناهج في التدفق الحالي بصورة متوقعة من المدخلات المسموح بها. فبيانات DLD المؤهلة توفر المقارنات، لكن مدخل الدخل لا ينشأ إلا من `annualRentAed` الذي يقدمه المستخدم، ومدخل التكلفة لا ينشأ إلا عند وجود replacement cost وdepreciation، وDCF محذوف عمداً لأنه يتطلب NOI مستقلاً.[5] وعند توفر بعض المناهج فقط، يختبر المحرك بالفعل نتيجة `partial` قابلة للاستخدام بدلاً من إلزام وزن المنهج الغائب داخل القيمة النهائية.[2]

| الوقائع المحسومة                                                            | المرجع  |
| --------------------------------------------------------------------------- | ------- |
| صيغة السلوك الحالي هي `wᵢ / Σ(active weights)` للمناهج المتاحة فقط.         | [1]     |
| قاعدة السلوك معلنة في metadata والتحذيرات كـ`PROVISIONAL`.                  | [1] [2] |
| الأوزان الكاملة لكل سيناريو مجمدة في المصدر الكانوني.                       | [3] [4] |
| DLD وحده لا يوفر rent أو replacement cost/depreciation أو NOI اللازم لـDCF. | [5]     |
| يمكن أن تكون نتيجة التقييم الجزئية قابلة للاستخدام عندما يتعذر بعض المناهج. | [2]     |

## ما هو غير محسوم

لا تحدد وثيقة المنهجية أو ADR-011 سياسة معتمدة تجيب عن أي من الأسئلة التالية: هل يجوز أصلاً إعادة توزيع وزن منهج غائب؟ هل القاعدة متاحة لكل نوع عقار ولكل توليفة من المناهج؟ هل تبقى نتيجة مقارنة المبيعات وحدها مقبولة أم يجب رفض التقييم؟ وما العلاقة الحاكمة بين حالة `partial` ونطاقات الثقة أو الإفصاح النهائي؟[3] [4] [6]

كما لا توجد في مصادر DLD المتاحة بيانات مستقلة عن الإيجار أو التكلفة أو NOI تسمح بإثبات أن إعادة التطبيع تنتج قيمة عادلة أو أدق من الرفض عند غياب منهج. التنفيذ الحالي يثبت **ما يفعله النظام**، ولا يثبت **أن هذه السياسة معتمدة أو سليمة منهجياً**.[1] [5] [6]

| فجوة السياسة                   | لماذا لا يمكن حسمها هنا                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| قابلية إعادة التطبيع بحد ذاتها | المصدر يصف سلوكاً مؤقتاً ولا يحتوي اعتماداً منهجياً.                                  |
| توليفات المناهج المسموح بها    | الأوزان الكاملة متاحة، لكن لا توجد matrix لغياب منهج واحد أو أكثر.                    |
| سلوك الرفض أو النتيجة الجزئية  | التنفيذ يطبق `partial`، لكن لا توجد سياسة معتمدة تحدد متى تكون النتيجة قابلة للتسليم. |
| تحقق الدقة أو المعايرة         | سجل DLD الحالي لا يقدم المدخلات المستقلة للمنهج الغائب لتقييم هذا القرار.             |

| ج      | وضع عتبات أو coefficients أو fallback مختلفة حسب نوع العقار.                                                           | محظور في هذه البوابة لغياب سند معتمد؛ لا يجوز تخمينه. |

## اتجاه المالك المعتمد

اختار مالك المشروع اتجاه البديل «أ»: يسمح المشروع بإعداد **إصدار منهجي مقترح فقط** قد يعرّف إعادة تطبيع الأوزان النشطة كسياسة للتعامل مع غياب منهج ذي وزن موجب. لا يوافق هذا الاختيار على الصيغة الحالية تلقائياً، ولا يغير الأوزان، ولا يسمح بالتنفيذ.[8]

يلزم ADR منهجي مستقل يحدد نطاق أنواع العقارات، وتوليفات المناهج المسموح بها، وسلوك الأدلة الناقصة، والإفصاح، وخطة تحقق مناسبة قبل تعديل المنهجية أو المحرك.[7]

## تأكيد عدم التدخل

لم يتغير في هذه البوابة أي ملف مصدر تشغيلي أو اختبار أو عقد أو قيمة أو API أو بيانات. تظل المنهجية `MIAYAAR-METH-001` v1.2 والمصدر الكانوني والأوزان والحسابات والتقييمات التاريخية كما هي.[3] [4]
