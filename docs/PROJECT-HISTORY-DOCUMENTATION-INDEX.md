# MIAYAAR Project History Documentation Index

## Purpose and scope

This index provides the repository-level route from each numbered delivery in the historical range **PR #2 through PR #67** to its authoritative implementation, governance, operations, security, or verification record. It is an index, not a replacement for the cited policy or verification record. The pull request is retained as the change-set authority; the linked repository document is the durable explanatory record where one exists.

The index was assembled from the GitHub pull-request history and the files changed by each merged request. It therefore records two important distinctions: a pull request may have changed executable code without adding a separate document, and a document-only pull request may preserve a governance decision without introducing executable behavior. ## Reading order

For a valuation decision, read the governing methodology first, then the applicable policy or contract, and finally the verification record for the delivered stage. For a historical delivery question, start with the relevant pull request and follow the document link in the table. This preserves the difference between a proposal, a policy gate, an implemented control, and a production verification.

## Coverage notes

The inclusive range contains sixty-six numbers. Two numbers, **#18** and **#19**, do not correspond to GitHub pull requests in the repository. PR #66 is intentionally shown as open because the request was within the requested number range at the time this index was created; it must not be read as an integrated delivery until it is merged. All other rows in the range correspond to merged pull requests. [1]
